RC-N3 按键映射
============================================================
首次实测: 2026-10-04 17:21:54（identify_buttons.py）
修正:     2026-10-07（游戏内实测，以此为准）


一、代码层面：位掩码 -> Xbox 键
============================================================
这部分由上游 shr101/dji-rc-n3 确定，本项目沿用，未做改动：

  0x1060  b1  ->  Xbox A
  0x1080  b2  ->  Xbox RT
  0x1004  b3  ->  Xbox X
  0x1002  b4  ->  Xbox RB
  0x1001       （未登记，上游代码未使用）


二、物理键 -> 位掩码 -> 游戏内效果
============================================================
以 2026-10-07 在《三角洲行动》中的实测为准：

  拍摄键      -> 0x1060 -> Xbox A  -> 跳跃
  返航键      -> 0x1080 -> Xbox RT -> 开火
  模式切换键  -> 0x1004 -> Xbox X  -> 换弹
  Fn 键       -> 0x1002 -> Xbox RB -> 游戏内未绑定

  云台波轮拨下 -> 十字键下 -> 切换瞄准镜倍率
  云台波轮拨上 -> 左扳机 LT -> 开镜（切换模式，见下）

四、踩坑记录：首次实测的物理键填表是错的
============================================================
2026-10-04 用 identify_buttons.py 识别后，把物理键填成：

  b1 = Fn, b2 = 模式切换, b3 = 拍摄, b4 = 返航

2026-10-07 游戏内实测证明，这四组全部错位。正确对应见第二节。

推测原因：识别脚本需要逐个按住物理键，若误按组合键
（如 Fn 需与其他键配合），或某次按错，会导致位掩码记录与
实际按键错位。

教训：
  - 以游戏内实际效果为准，不要直接采信识别工具的物理键填表。
  - identify_buttons.py 记录的「位掩码」本身是可靠的（代码层面映射），
    不可靠的是「位掩码 -> 物理键」这一层的人工填表。
